# IRS §6621 Interest Calculator (Open Source)

This repository contains a lightweight, open-source, client-side calculator
for computing interest under Internal Revenue Code §6621.

An official hosted version of this calculator is available at:
https://pfic.xyz/tools/irs-6621-interest-calculator/

This project is maintained by pfic.xyz.

---

## Scope

- IRS §6621 underpayment and overpayment interest calculations
- Static HTML / JavaScript / CSS implementation
- Intended for educational and reference use

---

## Disclaimer

This calculator is provided for informational purposes only and does not
constitute tax advice. Users are responsible for verifying results against
current IRS guidance.
